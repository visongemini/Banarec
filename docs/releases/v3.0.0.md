# BanaStudio 3.0.0

Banarec 从这一版起更名为 BanaStudio，应用程序和安装包文件名同步更新。

正式显示名为 BanaStudio，副标题为“录屏 · 截图 · 语音识别”。

## 语音识别

- 新增默认 **Flash 极速识别**：按下默认快捷键 `Ctrl + Alt + Space` 开始讲话，再按一次结束并获取最终文字。
- 可切换为按住讲话、松开结束。实时流式后端需要单独开通豆包资源授权；当前开发账户的流式授权验证被服务端拒绝，不能视为已真实验收。
- 最终文字保留在剪贴板；只有原编辑框、焦点和 UI Automation 标识仍一致时才自动粘贴一次，切换窗口或控件后回退到剪贴板，不会自动发送消息。
- 新增热词、历史与纠错；词库支持 JSON / CSV / TXT 合并导入，以及 JSON / CSV 导出。默认不保存原始音频。
- 开始语音识别时，麦克风音频与已启用热词会上传到豆包 ASR。录屏与截图仍在本机处理。

## 升级说明

- 新的应用程序文件名为 `BanaStudio.exe`，安装包为 `BanaStudio-Setup-3.0.0.exe`。
- 安装程序继续使用原 AppId，可直接覆盖升级已安装的 Banarec。
- 首次启动会把 `%LOCALAPPDATA%\Banarec\settings.ini` 复制到 `%LOCALAPPDATA%\BanaStudio\settings.ini`，旧文件仍会保留。
- 登录自启动沿用同一个注册表启动项并改为指向 `BanaStudio.exe`，避免升级后重复启动。
- 从旧版升级时沿用原安装目录；全新安装默认位于 `%LOCALAPPDATA%\Programs\BanaStudio`。

GitHub 仓库和 Releases 地址保持不变：[BanaStudio v3.0.0](https://github.com/visongemini/Banarec/releases/tag/v3.0.0)。
