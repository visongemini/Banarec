# Banarec 2.1.0

Windows 录屏与截图工具，首个公开发布版本。

## 截图标注

按 **Ctrl + Alt + A** 框选区域后进入标注窗口：

- 画笔、荧光笔和橡皮擦。
- 7 种颜色与可调笔迹粗细。
- 撤销 / 重做，支持 Ctrl+Z / Ctrl+Y。
- 点击“完成并复制”保存原始分辨率 PNG，并复制到剪贴板。
- Esc 或“取消”放弃本次截图。

## 录屏与常驻

- 全屏 / 区域录屏，原始像素 H.264 MP4，30 / 60 FPS。
- 系统声音与麦克风独立开关。
- 3 秒倒计时、区域边框和置顶录制浮框。
- 文件自动保存到下载文件夹。
- 托盘常驻，可选登录启动。
- 蕉仔 Banny 摄像机图标与暖白 WPF 界面。

## 下载

选择 `Banarec-Setup-2.1.0.exe` 安装，或下载 `Banarec-Portable-2.1.0.zip` 完整解压后运行 `Banarec.exe`。

要求 Windows 10 2004+ / Windows 11 x64、.NET Framework 4.8、VC++ x64 运行库和 Media Foundation。安装包不捆绑系统运行库，本版本未进行代码签名。

附件的 SHA-256 校验值见 `SHA256SUMS.txt`。

## 验证范围

已通过桌面集成测试：截图尺寸、剪贴板、取消操作、倒计时取消 / 重启、浮框停止和保存、全局快捷键、画笔颜色、荧光笔、橡皮擦、撤销 / 重做与原始分辨率导出。

长时间连续录制、4K / 60 FPS、特殊独占全屏、不同 DPI 多屏及其他电脑兼容性仍需进一步验证。
