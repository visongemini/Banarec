# Banarec 2.2.0

这一版把 Banarec 的窗口统一升级为半透明磨砂质感，并让截图和录屏快捷键都可以自由设置。

## 新增

- 主窗口、截图标注窗口、录制浮框采用 Windows 原生磨砂背景与圆角。
- 在偏好设置中点击快捷键按钮，直接按下新的组合键即可保存。
- 截图和开始 / 停止录屏可分别设置快捷键，并可恢复默认值。
- 首页快捷键提示和托盘菜单会实时显示当前设置。
- 快捷键被其他软件注册时自动启用兼容方式。

## 默认快捷键

- 截图：`Ctrl + Alt + A`
- 开始 / 停止录屏：`Ctrl + Shift + F9`

## 下载

选择 `Banarec-Setup-2.2.0.exe` 安装，或下载 `Banarec-Portable-2.2.0.zip` 完整解压后运行 `Banarec.exe`。

要求 Windows 10 2004+ / Windows 11 x64、.NET Framework 4.8、VC++ x64 运行库和 Media Foundation。安装包不捆绑系统运行库，本版本未进行代码签名。

附件的 SHA-256 校验值见 `SHA256SUMS.txt`。

## 验证范围

已通过界面、截图标注、录屏流程和快捷键桌面集成测试。快捷键测试覆盖默认截图键、自定义截图键、自定义录屏键、设置持久化，以及 Ctrl+A 正常全选。

长时间连续录制、4K / 60 FPS、特殊独占全屏、不同 DPI 多屏及其他电脑兼容性仍需进一步验证。
