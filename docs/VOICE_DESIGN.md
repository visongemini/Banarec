# BanaStudio 语音识别设计与验收

日期：2026-09-20。
状态：已在现有 Banarec 源码中完成 BanaStudio 3.0.0 实现。凭据以 Windows DPAPI 保存，不进入仓库。

实现调整：现有账户已实测支持 Flash 极速识别，首版默认说完出字；实时流式保留独立选项，但两个流式资源的握手都被服务端拒绝，需账户开通后才能实测。麦克风使用 Windows 默认输入设备；专有词通过热词和用户在历史中“纠正并记住”学习，不监听其他应用的编辑过程。以下是设计基线，实际交付及验证范围以 `VERIFICATION.md` 与 `ASR_INTEGRATION_NOTES.md` 为准。

## 目标与范围

用户确认参考 Typeless。在现有 Banarec 内新增“语音识别”板块，提供 Windows 全局语音输入，沿用现有窗口、托盘、设置、安装与升级方式。

首版交付包括免按模式、长按模式、豆包实时 ASR、结束后自动输入和剪贴板、专有词库、纠错记忆、词库导入导出、必要的转写历史和故障提示。现有录屏、截图、标注、快捷键、托盘功能必须回归验证。

“免按”指按一下开始、再按一下结束，不是常开麦克风或唤醒词监听。ASR 负责识别、标点与支持的文本规整；本范围不承诺复刻 Typeless 的大模型改写、翻译、问答或跨应用语义编辑。

## 当前已核验环境

- 旧版默认安装位置：`%LOCALAPPDATA%\Programs\Banarec\Banarec.exe`。
- 已核验源码使用 C# 5、WPF/WinForms、.NET Framework 4.8、ScreenRecorderLib 7.0.1；构建入口为 `build.ps1`，适用 Windows 10 2004+/Windows 11 x64。
- 现有默认截图键 Ctrl+Alt+A，录屏键 Ctrl+Shift+F9。
- 旧版参考安装包：`Banarec-Setup-2.2.0.exe`。
- 便携包：同目录 `Banarec-Portable-2.2.0.zip`。
- 未获得源码前不得重新写一个替代应用、反编译后覆盖安装版，或把安装包冒充源码。

## 用户流程

1. 在“语音识别 → 服务设置”配置豆包 ASR，选择麦克风，测试音量与连接。
2. 在任意应用点到输入位置，使用语音快捷键。非激活悬浮条显示音量、时长与实时文本，不抢焦点。
3. 免按模式再次触发结束；长按模式释放触发键结束；Esc 取消本次。
4. 等待服务端最终结果，原输入位置仍有效时自动粘贴一次，同时保留到剪贴板。不会模拟 Enter 发送消息。
5. 若目标已变化、原窗口关闭、权限不够或不能确认输入位置，保留文字并提示“已复制，请手动粘贴”，不往其他窗口盲目输入。

## 界面

在现有导航中加入“语音识别”，视觉沿用 Banarec 品牌和现有控件，不另开独立软件。

主区域包含：服务状态、所选麦克风、音量反馈、模式选择、快捷键、开始/结束按钮、实时转写区、最近一次最终文本、复制按钮。点击主界面的开始按钮默认作为试录/复制；只有从快捷键捕获到有效外部目标才自动输入，避免把配置页误当目标。

同板块提供“词库”“历史”“服务设置”入口。词库显示词语、常见误识别、来源（手动/导入/纠错学习）、启用状态和搜索；支持编辑、删除、批量导入、导出。历史提供时间、最终文本、复制、纠错保存、删除、清空和保留期限。默认只保存本地文字，不保存原始音频；可关闭历史。

悬浮条：空闲不遮挡；监听中显示音量和秒数；收尾中显示“正在完成识别”；失败时提供清晰原因与重试入口。取消后不复制、不输入、不保存误结果。

## 快捷键与状态机

建议首次默认 Ctrl+Alt+Space，在设置里选择免按或长按行为；以源码现有快捷键机制和冲突检测结果为准，不覆盖已有截图与录屏键。支持用户修改、冲突提示、恢复默认。

状态：Idle → Starting → Listening → Finalizing → Delivering → Idle。任意活动状态可 Cancel/Error → Cleanup → Idle。

- 按键自动重复不重复启动；Starting 时的释放/停止也必须被记住。
- 长按松开后只结束一次；短按未形成有效音频时无空文本输入。
- Finalizing 期间忽略额外开始操作并显示忙碌状态。
- 快捷键事件不得阻塞键盘钩子线程；网络和编码工作不在 UI 线程执行。
- 取消令牌和 session id 隔离迟到结果，确保每次最多输入一次。
- 每次退出、失败、取消必须释放麦克风、连接、计时器、钩子会话状态。
- 设置合理的最长单次时长与连接/收尾超时，达到上限明确告知并正常收尾，不无限录音或等待。

## 音频与豆包 ASR

采用官方当前可用的大模型实时流式接口。实际 endpoint、鉴权方式、Resource ID、音频格式、二进制协议、终包标识、热词字段及上限必须对照用户开通产品与官方 API 文档核实后实现。不要把通用豆包聊天 API Key 当作 ASR 凭据。

设置兼容实际账户使用的 API Key 或 App ID/Access Token 方案，并显示 Resource ID。凭据存储使用 Windows 当前用户保护机制（如 DPAPI），输入框遮罩；不写入日志、异常、导出文件、源代码或安装包。

采集默认仅麦克风；常用传输目标为单声道 16 kHz PCM16，最终以接口要求为准。按官方建议的小块连续发送；连接建立前音频使用有上限缓冲，避免丢开头。实时文本为显示预览，最终结果到齐再输入；不能把累计全文包逐包追加造成重复。

断网、授权失败、额度不足、设备拔出、无设备和无语音分别提示。失败时若只有未最终确认的文本，保留为可复制的未完成草稿，不能宣称成功，也不能自动粘贴不完整内容。默认不自动重发音频以免重复计费或重复输入。

麦克风测试可以本地完成；服务连通测试标明会调用 ASR。语音启用说明明确音频和启用的热词会发送给豆包；现有安装说明中的“不联网”必须调整为准确描述。

## 自动输入

开始时记录前台窗口与可确认的焦点控件；显示悬浮条使用不激活方式。结束时重新检查目标有效性，确认原位置没有被用户切换。支持时利用 UI Automation 验证目标身份与密码属性，不全局读取用户文本。

先通过带重试的剪贴板操作保存最终文本，再执行一次粘贴。保证触发快捷键的 Ctrl/Alt/Shift 已释放，避免组合键污染；如修饰键仍按住则等待有限时间，超时改为手动粘贴。不恢复旧剪贴板，因为用户明确要求保留新转写。

剪贴板持续被占用时保留本次结果并报错，不发送粘贴键以免插入旧内容。禁止盲目重复发送 Ctrl+V；SendInput 成功仅表示事件提交，不能据此断言目标已接收。权限限制、终端特殊快捷键和不可确认目标以复制回退。密码框等受保护目标不自动输入。

## 专有词与自动学习

词库的正确词语作为热词传给 ASR，提高姓名、品牌、项目名和英文缩写的识别概率；不保证每个词都正确。候选示例可以展示 Banarec、睡蕉等，但不把示例静默写入用户正式词库。

可靠的首版学习入口是“纠正并记住”：用户在本软件最近转写/历史中确认错误词与正确词后，自动保存正确词及可选错词映射，下次使用。多个同音近音词不能简单全局替换；词级边界、较长匹配优先、歧义提示和禁用开关要可测试。

自动发现新增生词只能形成待确认候选，不能把 ASR 错字自动固化成正确热词。Typeless 式在其他软件手动修改后学习，可在 UI Automation 能准确限定本次插入文本范围且目标身份稳定时实现；禁止通过全局键盘记录、无限轮询全文或读取其他输入框实现。若现有应用与平台不能可靠支持，明确交付限制，不将“纠正并记住”宣称为跨应用自动学习。

### 导入导出

- JSON 为完整备份格式，含 schemaVersion、word、aliases、enabled、source、timestamps，不包含凭据或历史转写。
- CSV 与 TXT 支持日常批量词表；TXT 每行一词；CSV 明确 word/aliases/enabled 列，兼容仅单列词语和 UTF-8 BOM。支持正确的引号、逗号与换行解析。
- 导入先预览新增、重复、冲突、无效条数；默认合并，不能静默清空现有词库。重复规则明确并保持英文显示大小写。
- 导入成功后原子保存；失败保持原文件；导出可重新导入并保持词语与启用状态。
- 空词、长度上限、超大文件、未知 schema 和畸形内容需校验。CSV 导出避免表格公式执行。
- 可提供自动备份最近有效词库，保留有上限；“自动导入”不做无边界文件夹监控。

## 最小实现结构

以源码组织为准，通常需要音频采集、ASR 客户端、输入投递、会话控制、词库存储及一个集成视图。尽量复用已有快捷键、设置、通知、剪贴板重试和托盘实现；不引入服务端、数据库服务或新的完整前端框架。

配置与词库应放在应用已有的用户数据目录，升级保留旧设置与数据。打包前保存原版可回退安装包和文件散列；测试版先独立运行，不能结束正在进行的用户录屏。

## 验收清单

1. 构建成功，可启动；原版录屏/截图/标注/托盘/快捷键/设置仍可用。
2. 免按开始与结束；长按释放结束；重复 keydown、Starting 期间释放、Esc、超时均正确，单会话无重复结果。
3. 真实麦克风到真实豆包流式 ASR，看到中间结果并获得最终文本；中文、数字、标点、中英混合实际测试。
4. 普通编辑器与浏览器输入框：光标位置正确，文字仅输入一次，剪贴板保留同一结果，不自动发送消息。
5. 切换窗口、关闭原窗口、剪贴板占用、修饰键未释放、权限不同的目标都能安全回退，不误输入旧内容或错窗口。
6. 词库增删改、启用禁用、纠错记忆、重复与冲突导入、UTF-8 中文、CSV 引号、畸形 JSON、导出重导入验证通过。
7. 协议测试覆盖分片、压缩、错误帧、最终包、空语音、累计结果与取消后迟到消息；不可只有成功路径 mock。
8. 取消、失败、退出后麦克风停止；不记录密钥、不保存音频，历史与词库保留策略有效。
9. 用户真实专有词读音与正确写法需要真人试说验收。缺凭据/真人语音时应列为未验证，不得把 mock 成功写成真实服务通过。
