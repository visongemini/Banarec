Banarec · 香蕉录屏 2.1

录屏
选择显示器及全屏/框选区域，设置系统声音和麦克风后开始。
3 秒倒计时后录制，红色边框标出录制区域，置顶浮框显示状态及停止按钮。
浮框可拖动，停止后等待保存完成。Ctrl + Shift + F9 开始/停止。
原生像素 H.264 MP4，高画质 30/60 帧可选。奇数宽高录制时向内对齐 1 像素。

截图
Ctrl + Alt + A，或打开“截取画面”，拖动框选，松开进入标注窗口。Esc / 右键取消。
支持跨显示器框选。可选画笔、荧光笔、橡皮擦、7 种颜色及笔迹粗细，支持撤销/重做。
点击“完成并复制”保存原始像素 PNG，同时复制到剪贴板，可直接粘贴。
剪贴板被占用时重试，仍失败会提示，PNG 文件仍保存。
录像和截图都自动保存至 Windows 下载文件夹，按日期和时间命名。
录制过程中先停止再截图，以免截图操作影响正在录制的画面。

常驻
关闭主窗口会驻留托盘，右键托盘可截图、录屏、打开文件夹及完全退出。
登录启动时只驻留托盘，不弹窗。可在偏好设置中关闭登录启动。
Ctrl + Alt + A 已被别的软件注册时，Banarec 会在运行期间优先响应这个组合键。
可以在偏好设置中关闭全局截图快捷键；Ctrl+A 仍为正常全选。
不采集、不保存键入内容，不联网，不上传屏幕内容，不添加管理员服务。

路径
安装：%LOCALAPPDATA%\Programs\Banarec
设置：%LOCALAPPDATA%\Banarec\settings.ini
卸载：Windows 设置 → 应用 → Banarec · 香蕉录屏。
卸载不会删除你保存的录像和截图。

验证
本机已验证：新界面渲染，321×181 PNG 原始尺寸、剪贴板、截图取消，
录制倒计时取消和重启，录制浮框停止，以及 MP4 保存和完整解码。
录制核心沿用已验证的 ScreenRecorderLib 7.0.1。
长时间录制、特殊独占全屏、4K/60 帧及不同机器仍需实际使用验证。
安装需要 Windows 10 2004+ / Windows 11 x64、.NET Framework 4.8、VC++ x64 运行库。
本机已具备这些运行环境。系统声音使用默认输出设备，麦克风使用默认输入。

图标
蕉仔 Banny 正在录视频；基于你提供的无斑日常版角色模卡，通过内置 imagegen 生成。
原始图和生成说明保存在项目 assets 文件夹。

快捷键实测补充：Ctrl+Alt+A 在已有占用的情况下成功触发一次截图，Ctrl+A 仍正常全选。
