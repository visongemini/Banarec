BanaStudio 3.0
录屏 · 截图 · 语音识别

录屏
选择显示器及全屏/框选区域，设置系统声音和麦克风后开始。
3 秒倒计时后录制，红色边框标出录制区域，置顶浮框显示状态及停止按钮。
浮框可拖动，停止后等待保存完成。默认 Ctrl + Shift + F9 开始/停止。
原生像素 H.264 MP4，高画质 30/60 帧可选。奇数宽高录制时向内对齐 1 像素。

截图
默认 Ctrl + Alt + A，或打开“截取画面”，拖动框选，松开进入标注窗口。Esc / 右键取消。
支持跨显示器框选。可选画笔、荧光笔、橡皮擦、7 种颜色及笔迹粗细，支持撤销/重做。
点击“完成并复制”保存原始像素 PNG，同时复制到剪贴板，可直接粘贴。
剪贴板被占用时重试，仍失败会提示，PNG 文件仍保存。
录像和截图都自动保存至 Windows 下载文件夹，按日期和时间命名。
录制过程中先停止再截图，以免截图操作影响正在录制的画面。

语音识别
在“语音识别”中配置豆包 ASR。默认 Ctrl + Alt + Space，支持按一下开始/再按一下结束，或按住讲话/松开结束。
默认 Flash 模式在说完后一次返回结果；实时流式模式需要单独开通豆包资源授权，当前未完成真实验收。
最终文字会保留到剪贴板；只有原输入框和焦点仍一致时才自动粘贴一次，目标失效时回退到剪贴板，不会自动发送消息。
语音历史和热词保存在本机；词库支持导入、导出与纠错记忆，默认不保存原始音频。
启用语音识别时，麦克风音频和已启用的热词会发送给豆包 ASR。

快捷键
截图默认 Ctrl + Alt + A，录屏默认 Ctrl + Shift + F9，语音默认 Ctrl + Alt + Space。
截图和录屏快捷键在偏好设置中修改，语音快捷键在语音识别页修改。
新快捷键需要包含 Ctrl、Alt 或 Shift；被别的软件占用时会自动启用兼容方式。
没有设为快捷键的 Ctrl+A 等组合仍保持原有行为。

常驻
关闭主窗口会驻留托盘，右键托盘可截图、录屏、打开文件夹及完全退出。
登录启动时只驻留托盘，不弹窗。可在偏好设置中关闭登录启动。
不采集或保存其他键入内容；录屏和截图在本机处理，不上传屏幕内容，不添加管理员服务。

路径
安装：新安装默认为 %LOCALAPPDATA%\Programs\BanaStudio；从 Banarec 升级时沿用原安装目录
设置：%LOCALAPPDATA%\BanaStudio\settings.ini（首次启动复制旧 Banarec 设置，原文件保留）
卸载：Windows 设置 → 应用 → BanaStudio。
卸载不会删除你保存的录像和截图。

验证
2.2 版原有功能曾在本机验证：半透明磨砂界面渲染，321×181 PNG 原始尺寸、剪贴板、截图取消，
录制倒计时取消和重启，录制浮框停止，以及 MP4 保存和完整解码。
默认键、自定义截图键、自定义录屏键和设置持久化均通过，Ctrl+A 仍正常全选。
录制核心使用已验证的 ScreenRecorderLib 7.0.1。
3.0 版语音识别和完整回归测试须使用真实麦克风与真实豆包账户验收。
长时间录制、特殊独占全屏、4K/60 帧及不同机器仍需实际使用验证。
安装需要 Windows 10 2004+ / Windows 11 x64、.NET Framework 4.8、VC++ x64 运行库。
本机已具备这些运行环境。系统声音使用默认输出设备，麦克风使用默认输入。
